# Contributing to Tesserae V6

Tesserae is a free, noncommercial research service. Contributions are welcome, whether a text for the corpus, a correction, a translation alignment, a fix or a feature. This page says how to send one and what you agree to when you do.

## How to contribute

- **A text or a correction:** use the "Upload Your Text" page in Help, or the request link in the site header. Pre-formatted `.tess` files are processed faster. Name the edition and its license.
- **Code:** open a pull request against `main`. Every pull request runs the test suite, the lint, the Help coverage check and an automated review. A maintainer reads the review and merges. A change a visitor can see updates the Help page in the same pull request.
- **Working notes and data** stay out of the repository. The repository carries code and the three public records (CHANGELOG, docs/DECISIONS.md, docs/DATA_OPERATIONS.md).
