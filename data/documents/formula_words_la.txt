# vocabulary (dis manibus, vixit annis, the Roman naming/filiation

# added by hand that the document-frequency pass did not surface on

# Explicitly EXCLUDES personal names and praenomina/filiation forms
# (caius, lucius, marcus, cai, luci, marci and similar): those belong in
# a name list, not a formula list, and are tracked separately.
# Explicitly EXCLUDES numerals.

# USE: a SOFT penalty on matches built from these words (like a function
# word list), not a hard stoplist. A genuine parallel built partly from
# "dis manibus" or "vixit annis" is still a real parallel; these words
# should count for less toward a match's distinctiveness, not be thrown
# out.
