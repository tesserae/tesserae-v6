# License of each electronic source

Every credit row in `backend/text_sources.json` now carries a `license` field. This table lists the rule used for each source, the wording written, the number of rows it filled on 2026-10-25, and the page or file read to confirm it. Rows that already had a license were not touched. The license is that of the electronic text as the source distributes it. The editions themselves are usually public domain by date, but Perseus and Open Greek and Latin license their own markup and transcription.

|---|---|---|---|
