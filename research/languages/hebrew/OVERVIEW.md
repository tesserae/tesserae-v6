# Hebrew

**Live.** 39 works, the full Tanakh (23,206 lines), plus the Septuaginta as a
Greek parallel.

- Text: Miqra according to the Masorah (MAM), based on the Aleppo Codex, via
  Sefaria, CC-BY-SA.
- Morphology: ETCBC/BHSA, **CC-BY-NC 4.0**. That restriction passes to anything
  derived from it, which is why the Hebrew slice of the released passage index is
  non-commercial and is published separately.
- 5,372 passage windows in the content index.
- An in-house fine-tuned Hebrew semantic model raised thematic performance from
  0.27 to 0.51.
- Hebrew-to-Greek dictionary enables Old-Testament-in-New-Testament discovery
  (e.g. Hab 2:4 -> Gal 3:11).

**Note:** the name check cannot run on Hebrew script, since an English
participant name will never match literally. Those records are recorded as
uncheckable rather than failed.
