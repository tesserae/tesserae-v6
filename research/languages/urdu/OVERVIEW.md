# Urdu

**Content index only.** 2,148 passage windows.

- Ghalib (d. 1869) and Iqbal (d. 1938).
- The underlying poetry is public domain; the texts were parsed from Rekhta
  (rekhta.org), which should be credited as the digitisation source.
- The released slice contains **no Urdu text**: English descriptions,
  embeddings and reference tags only, with Arabic-script characters appearing
  only in a radif letter inside a citation. Redistributing it does not
  redistribute anyone else digitisation.
- A lexical index exists in `~/tesserae-multilang` (`ur_index.db`) on branch
  `feature/multilang-ship`, not merged.

**Same caution as Persian:** the ghazal tradition answers through shared radif
and metre, which content descriptions do not see.
