Tesserae API & ChatGPT Integration — Privacy Policy

This page explains, in plain terms, what happens to your data when Tesserae's open search API is used — including when you use it through a ChatGPT “Custom GPT” or another AI assistant. It describes the API only; the interactive website has its own privacy policy.

The service

Tesserae is a free, non-commercial scholarly tool operated by the Tesserae project at the University at Buffalo. Its search API is open and keyless: there is no account, sign-in, or API key. When an AI assistant such as a ChatGPT Custom GPT searches Tesserae for you, it sends ordinary web requests to tesserae.caset.buffalo.edu. ChatGPT may ask your permission the first time before contacting the Tesserae server — that is the normal Custom-GPT permission prompt.

What is sent to Tesserae

Each search request carries only the search parameters — for example the two text ids being compared, a search word or phrase, a language code, or an author filter. Because it is keyless, no ChatGPT account details, no API key, and no login identifier are sent. As with any request over the internet, the request also carries the network IP address it comes from.

The Tesserae corpus is public classical literature, and searches are ordinary scholarly queries. Please do not put personal, confidential, or sensitive information into your searches — search terms are logged (see below).

What Tesserae records

For most search requests, the server writes a log entry containing:

  • the search type and its parameters (the text ids compared, or the query word/phrase, and the language);
  • the number of results and a timestamp;
  • the requesting IP address, and an approximate city and country derived from it.

These entries are used to understand load and usage of the shared research server. Some requests are not logged — listing texts or languages, and the “polling” search endpoints, record no such entry.

Approximate location lookup

To turn an IP address into an approximate city and country, Tesserae sends the IP to a third-party geolocation service (ipinfo.io, with ip-api.com as a fallback). This yields only a coarse, city-level location — never a precise position — and is subject to those services' own terms.

Retention

Search-log entries (including the IP address and approximate location) are stored on the Tesserae server and are currently retained indefinitely; there is no automatic deletion. Aggregated, de-identified usage may inform research on the Tesserae methods; no personally identifying information is included in research publications. You may contact the project (below) to ask about, or request deletion of, log data associated with your IP address.

Cookies, tracking, and caching

The API sets no cookies for anonymous search requests and uses no advertising or analytics trackers. To make repeated searches fast, Tesserae caches search results keyed by the search parameters; that results cache stores no IP address, location, or other personal data.

Feature or bug requests

If you ask the assistant to file a feature, text, or bug request on your behalf — and only after you explicitly confirm it — the request text is posted as a public GitHub issue for the development team. Any contact email you choose to include is kept private: it is stored for the team and is not placed in the public issue.

Other data flows

Tesserae does not sell or share your data. The only outbound data flows are those described above: the geolocation lookup, and (for a confirmed feature/bug request) filing a GitHub issue with the contact removed. Dictionary look-ups on the website may consult Wiktionary/Perseus, but those are part of the interactive site, not the search API.

Contact

For privacy questions or a data-deletion request, contact the Tesserae project team through the feedback form in the website's Help & Support section, or the contact listed on the About page.
