Use Tesserae with your AI

Let your own AI assistant run Tesserae searches for you — comparing texts, testing parallels for uniqueness across the corpus, and helping you interpret. Tesserae does the searching, free, on an open API; your assistant orchestrates and interprets. There are three ways to connect, from simplest to most capable.

1 · Paste-in guide

Any AI. Copy a guide into ChatGPT, Claude, or any web-capable assistant. Zero setup.

2 · ChatGPT Custom GPT

ChatGPT Plus. A reusable "Tesserae" GPT your students and colleagues can just talk to.

3 · Claude (MCP)

Most capable. A connector that lets Claude run even the full fusion search.

A note on scholarly use (applies to all three). Tesserae's results — the parallels, loci, and rarity — are transparent and reproducible: anyone can re-run a search and inspect why a match ranked where it did. Whatever your AI concludes from there is its own product. When you publish, cite Tesserae for the parallels it found, and present the surrounding analysis as AI-assisted interpretation you have checked.

2ChatGPT Custom GPTChatGPT Plus

Build a reusable "Tesserae" GPT once; then you (and anyone you share it with) just chat with it. Custom-GPT building is included in ChatGPT Plus ($20/mo) — find it under Explore GPTs → “+ Create” (top-right).

  1. In ChatGPT: Explore GPTs → + Create → Configure. Name it Tesserae.
  2. Paste the instructions below into the Instructions box.
  3. Actions → Create new action → Import from URL, and paste the schema URL below. Set Authentication: None.
  4. Test it (e.g. “List Vergil's texts”, “How rare is arma virumque across the corpus?”), then Save — privately or as a shared link.

Schema URL (for the Action)

https://tesserae.caset.buffalo.edu/tesserae-data/tesserae-openapi.yaml

Instructions (paste into the GPT)

You are Tesserae, an assistant for finding intertextual parallels (allusions, echoes, quotations) in classical literature, using the provided Tesserae actions.

- Follow the user's lead; they are the scholar. Surface a relevant capability briefly when useful, then defer.
- Typical workflow: identify two texts (listTexts) -> find distinctive shared vocabulary (rarePairsSearch / rareWordsSearch) -> test how unique a shared phrase is across the whole corpus (lineSearch) -> interpret the strongest, rarest parallels, quoting both passages and their loci.
- Do NOT call fusionSearch (it streams and is long-running). For two-text comparison use rarePairsSearch/rareWordsSearch; for full weighted fusion, point the user to the web app at https://tesserae.caset.buffalo.edu.
- PROVENANCE (important): keep Tesserae's results and your own interpretation clearly separate. Attribute matches, loci, and rarity to Tesserae (transparent, reproducible); present your analysis as AI-assisted inference the scholar should verify. Encourage citing Tesserae for the parallels and describing surrounding analysis as AI-assisted.
- Always show the actual passages and loci; be candid about weak matches. Language codes: la (Latin), grc (Greek), en (English), cop (Coptic).

Note: ChatGPT Actions can't stream, so the GPT does two-text comparison via rare words / rare pairs and points users to the web app for the full fusion search. For full fusion from an AI, use route 3.

3Claude, via an MCP serverMost capable

MCP (Model Context Protocol) lets Claude call Tesserae directly. Because MCP tools aren't limited to a few seconds, this route can run the full fusion search, not just rare words/pairs. It needs Python on your machine.

  1. Download the server: tesserae_mcp.py
  2. Install its dependencies: 
    pip install "mcp[cli]" requests
  3. Claude Desktop: Settings → Developer → Edit Config, and add (use the real path to the file): 
    {
  "mcpServers": {
    "tesserae": {
      "command": "python",
      "args": ["/full/path/to/tesserae_mcp.py"]
    }
  }
}
    Claude Code: instead run 
    claude mcp add tesserae -- python /full/path/to/tesserae_mcp.py
  4. Restart Claude, then ask, e.g.: “Use Tesserae to compare Aeneid 1 with Lucan's Civil War 1 and show the strongest parallels.”
